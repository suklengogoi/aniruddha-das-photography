# Aniruddha Das Photography — website (v2, rebuilt from scratch)

Static site: HTML, CSS and vanilla JS. No build step, no libraries, no external requests (fonts are self-hosted).
Deploy by copying everything in this folder to the repo root (GitHub Pages).

- `index.html` home: hero, about, albums deck, reels strip, services over a still picture, contact
- `gallery.html?album=couples|bridal|ceremony|details|monochrome` album pages
- `films.html` films and reels, `404.html`
- `js/data.js` edit contact details, albums (tint colour per album) and films here
- `assets/` photos, videos, fonts (Fraunces and Manrope, SIL OFL licences included)
